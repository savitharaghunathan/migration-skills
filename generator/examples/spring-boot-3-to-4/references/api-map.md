# API Map — Spring Boot 3 to 4

| old_api | new_api | kind | action | before | after | notes | source_section |
|---|---|---|---|---|---|---|---|
| org.springframework.lang.Nullable | org.jspecify.annotations.Nullable | annotation | replace | `import org.springframework.lang.Nullable;` | `import org.jspecify.annotations.Nullable;` | jspecify replaces Spring's nullability annotations | Nullable Annotations |
| org.springframework.lang.NonNull | org.jspecify.annotations.NonNull | annotation | replace | `import org.springframework.lang.NonNull;` | `import org.jspecify.annotations.NonNull;` | | Nullable Annotations |
| javax.annotation.Nonnull | org.jspecify.annotations.NonNull | annotation | replace | `import javax.annotation.Nonnull;` | `import org.jspecify.annotations.NonNull;` | JSR-305 annotations removed | Nullable Annotations |
| org.springframework.boot.web.server.LocalServerPort | removed | annotation | remove | `@LocalServerPort int port;` | `@Value("${local.server.port}") int port;` | Use @Value injection instead | Removed Annotations |
| org.springframework.boot.autoconfigure.web.servlet.error.AbstractErrorController | removed | class | remove | `extends AbstractErrorController` | Implement `ErrorController` directly | Simplified error handling | Error Handling |
| org.springframework.http.client.HttpComponentsClientHttpRequestFactory | org.springframework.http.client.HttpComponentsClientHttpRequestFactory | class | replace | `new HttpComponentsClientHttpRequestFactory(HttpClients.createDefault())` | `new HttpComponentsClientHttpRequestFactory(HttpClient5.createDefault())` | Constructor takes HttpClient 5 instance | HTTP Client |
| org.springframework.boot.context.properties.ConstructorBinding | removed | annotation | remove | `@ConstructorBinding` | (remove — constructor binding is the default in SB4) | Annotation no longer needed; single-constructor records auto-bind | Configuration Properties |
| org.springframework.boot.actuate.health.HealthIndicator | org.springframework.boot.actuate.health.HealthIndicator | interface | replace | `implements HealthIndicator` | `implements HealthIndicator` | Same interface, but `health()` return type changed from `Health` to `HealthComponent` | Actuator |
| org.springframework.web.bind.annotation.RequestMapping | org.springframework.web.bind.annotation.RequestMapping | annotation | replace | `@RequestMapping(method = RequestMethod.GET)` | `@GetMapping` | Method-specific annotations preferred; `@RequestMapping` still works but deprecated at class level | Web MVC |
| org.springframework.boot.web.servlet.FilterRegistrationBean | org.springframework.boot.web.servlet.FilterRegistrationBean | class | replace | `FilterRegistrationBean<MyFilter>` | `FilterRegistrationBean<MyFilter>` | Generic type now required (was optional) | Servlet |
| org.springframework.scheduling.annotation.Scheduled | org.springframework.scheduling.annotation.Scheduled | annotation | replace | `@Scheduled(fixedDelay = 5000)` | `@Scheduled(fixedDelay = "5s")` | Duration strings now accepted; long values still work | Scheduling |
| org.springframework.core.env.Profiles | org.springframework.core.env.Profiles | class | replace | `Profiles.of("dev", "test")` | `Profiles.of("dev", "test")` | Factory methods renamed; `of()` still works | Profiles |
| org.springframework.boot.ApplicationRunner | org.springframework.boot.ApplicationRunner | interface | replace | `void run(ApplicationArguments args)` | `void run(ApplicationArguments args) throws Exception` | Checked exception now declared | Application Lifecycle |
| org.springframework.test.context.junit4.SpringRunner | removed | class | remove | `@RunWith(SpringRunner.class)` | `@SpringBootTest` (no runner needed with JUnit 5) | JUnit 4 support removed | Testing |
| org.springframework.boot.test.mock.mockito.MockBean | org.springframework.test.context.bean.override.mockito.MockitoBean | annotation | move_package | `import org.springframework.boot.test.mock.mockito.MockBean;` | `import org.springframework.test.context.bean.override.mockito.MockitoBean;` | Renamed and relocated | Testing |
