# Pattern Map — Spring Framework 4 to 5

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| JDK 8 is the minimum baseline; JDK 9+ module path supported | addition | | Compile and deploy with JDK 8+ (Java SE 8 update 60 minimum recommended) | Full JDK 9 compatibility on classpath and module path (Jigsaw) | Baseline Update (5.0) |
| Java EE 7 API level required (Servlet 3.1, JPA 2.1, Bean Validation 1.1, JMS 2.0) | addition | | Upgrade application server to one supporting Java EE 7+ | Runtime compatibility with EE 8 (Servlet 4.0, JPA 2.2, Bean Validation 2.0) | Baseline Update (5.0) |
| Minimum Tomcat 8.5+, Jetty 9.4+, WildFly 10+, WebSphere 9+ | addition | | Upgrade servlet container to supported version | Netty 4.1 and Undertow 1.4 added for WebFlux | Web Servers (5.0) |
| spring-jcl replaces commons-logging; auto-detects Log4j 2, SLF4J, JUL | structural | `<exclusion><groupId>commons-logging</groupId><artifactId>commons-logging</artifactId></exclusion>` | Remove commons-logging exclusions; spring-jcl in spring-core handles bridging automatically | May still need explicit excludes for commons-logging in other libraries | Commons Logging Setup (5.0) |
| CORS `allowCredentials` default changed from implicit `true` to explicit `false` | behavioral | `@CrossOrigin` | `@CrossOrigin(allowCredentials = "true")` | Cookies/authentication in CORS requests now require explicit `allowCredentials=true` | CORS Support (5.0) |
| Null-safety annotations: Spring APIs no longer tolerate null in some cases | behavioral | `StringUtils.hasText(null)` | Check for null before calling; APIs annotated with `@Nullable` indicate where null is accepted | `@Nullable` annotations added across the framework for IntelliJ IDEA and Kotlin support | Null API (5.0) |
| XML config namespaces streamlined to unversioned schemas | structural | `<beans xmlns="http://www.springframework.org/schema/beans" xsi:schemaLocation="... spring-beans-4.3.xsd">` | `<beans xmlns="http://www.springframework.org/schema/beans" xsi:schemaLocation="... spring-beans.xsd">` | Version-specific declarations still work but resolve to latest schema; deprecated features removed from schema | Core Container (5.0) |
| Candidate component index as alternative to classpath scanning | addition | | Add `spring-context-indexer` annotation processor for faster startup | Optional optimization; generates `META-INF/spring.components` at compile time | Core Container (5.0) |
| FreeMarker macros (spring.ftl) use HTML output formatting | behavioral | | Requires FreeMarker 2.3.24+ | Affects template rendering if using Spring's FreeMarker macros | Spring Web MVC (5.0) |
| Spring WebFlux module introduced as reactive alternative to spring-webmvc | addition | | Add `spring-webflux` dependency for reactive web applications | New programming model; includes `WebClient`, `@Controller` on reactive stack, functional endpoints | Spring WebFlux (5.0) |
| `AsyncRestTemplate` deprecated in favor of `WebClient` | removal | `AsyncRestTemplate asyncRest = new AsyncRestTemplate();` | `WebClient client = WebClient.create();` | WebClient provides reactive, non-blocking HTTP calls | Spring WebFlux (5.0) |
| JUnit 5 Jupiter support via `SpringExtension` | addition | `@RunWith(SpringRunner.class)` | `@ExtendWith(SpringExtension.class)` or `@SpringJUnitConfig` | JUnit 4 still supported; new `@EnabledIf`/`@DisabledIf` annotations for conditional tests | Testing (5.0) |
| Nested configuration classes only detected on `@Configuration`/`@Component` stereotyped classes | behavioral | | Add `@Configuration` or `@Component` to containing classes if relying on nested class detection | Previously over-introspected nested classes on non-stereotyped classes | Nested Config Classes (5.1) |
| Forwarded headers no longer checked individually; must use `ForwardedHeaderFilter` | behavioral | Forwarded/X-Forwarded-* headers checked in same-origin CORS checks, `MvcUriComponentsBuilder` | Configure `ForwardedHeaderFilter` or proxy-level forwarded header support | Filter has safe mode to check and discard headers | Forwarded Headers (5.1) |
| `DefaultUriBuilderFactory` enforces stricter URI variable encoding by default | behavioral | `DefaultUriBuilderFactory factory = new DefaultUriBuilderFactory();` | Call `factory.setEncodingMode(...)` to adjust if needed | Impacts WebClient with default settings | URI Encoding (5.1) |
| `@RequestMapping` produces condition no longer impacts error response content type | behavioral | | Error response content type determined independently | | Content Negotiation (5.1) |
| Multipart parameter values aggregated with query parameters per Servlet spec 3.1 | behavioral | | Multipart params and query params now combined | Previously returned only multipart values if present | Multipart Values (5.1) |
| HTTP OPTIONS consistently included as supported HTTP method | behavioral | | OPTIONS always in supported methods | Previously not always included | HTTP OPTIONS (5.1) |
| WebFlux session cookies default to `SameSite=Lax` | behavioral | | Cookies written directly to `Set-Cookie` header with `SameSite=Lax` | Protects against CSRF; cookie validation conforms to RFC 6265 section 4.1 | WebFlux Cookies (5.1) |
| Hibernate read-only transactions no longer retain entity snapshots | behavioral | | `Session.setDefaultReadOnly(true)` set by default on read-only transactions | Reduces memory usage; may affect code relying on dirty checking in read-only tx | Spring ORM (5.1) |
| JDK 11 supported; ASM 7.0 fork for JDK 11/12 bytecode levels | addition | | Compile with `-target 1.8` for defensive upgrade to JDK 11 | CGLIB uses JDK 9+ API for class definition; fallback may log JVM warnings | JDK 11 (5.1) |
| Annotations must have `@Retention(RetentionPolicy.RUNTIME)` for Spring to find them | behavioral | `@interface MyAnnotation { }` | `@Retention(RetentionPolicy.RUNTIME) @interface MyAnnotation { }` | Annotation retrieval algorithms completely revised in 5.2 for efficiency | Core Container (5.2) |
| `@RequestMapping()` without path now matches only empty path (was any path) | behavioral | `@GetMapping()` matched any URL | `@GetMapping()` only matches URLs with no path; use `@GetMapping("/**")` for all paths | Applies to `@GetMapping`, `@PostMapping`, etc. without explicit `path` | RequestMapping Path (5.2) |
| `@Configuration(proxyBeanMethods=false)` lite mode without CGLIB subclasses | addition | `@Configuration` | `@Configuration(proxyBeanMethods = false)` | Avoids CGLIB proxy; bean method calls won't return singleton; use method arguments for dependencies | Configuration (5.2) |
| `Web*ConfigurationSupport` subclasses should use method arguments for bean dependencies | structural | `@Bean Formatter formatter() { return conversionService().addFormatter(...); }` | `@Bean Formatter formatter(FormattingConversionService conversionService) { ... }` | Required when using `proxyBeanMethods=false`; Spring Boot 2.2+ uses this | EnableWebMvc Infrastructure (5.2) |
| Suffix pattern matching and path extension content negotiation deprecated | removal | `configurer.setUseSuffixPatternMatch(true)` | Remove suffix pattern matching config; use `Accept` header or query parameter for content negotiation | Config options deprecated in 5.2; disabled by default in 5.3 | Path Extensions (5.2) |
| Custom `Encoder` implementations must implement `encodeValue` method | structural | | Implement `Encoder#encodeValue` (invoked from `ServerSentEventHttpMessageWriter`) | Fails at runtime without implementation | Encoder Contract (5.2) |
| Mock JNDI support deprecated in spring-test | removal | `SimpleNamingContextBuilder.emptyActivatedContextBuilder()` | Use third-party JNDI: Simple-JNDI (h-thurow/Simple-JNDI) | `SimpleNamingContext` and `SimpleNamingContextBuilder` deprecated | Testing (5.2) |
| WebFlux codecs limit input to 256K by default (`maxInMemorySize`) | behavioral | Unlimited input buffering | `maxInMemorySize` set to 256K; configure higher if needed | `FormHttpMessageReader` limited to 256K in 5.1; all codecs in 5.2 | WebFlux Codecs (5.2) |
| ReactiveTransactionManager SPI for reactive transaction management | addition | | Use `ReactiveTransactionManager` or `TransactionalOperator` for reactive transactions | `@Transactional` works with reactive return types | Transaction Management (5.2) |
| WebMvc.fn functional programming model added (Servlet-based) | addition | | Use `RouterFunction` for functional endpoints on Servlet stack (analogous to WebFlux.fn) | Alternative to annotated controllers; includes Kotlin DSL | Spring Web MVC (5.2) |
| Kotlin Coroutines support in WebFlux | addition | | Coroutines support for `@Controller` methods and `WebClient` | Requires Kotlin 1.3+ and Kotlin Coroutines 1.4+ (5.3) | Spring WebFlux (5.2) |
| CORS `allowCredentials=true` now requires explicit domain list (no wildcard `*`) | behavioral | `config.setAllowedOrigins(Arrays.asList("*"));` | `config.setAllowedOriginPatterns(Arrays.asList("*"));` | Use `allowedOriginPatterns` for wildcard domains when `allowCredentials=true` | CORS (5.3) |
| Double-wildcard mid-pattern `"/path/**/other"` rejected by PathPatternParser | behavioral | `@GetMapping("/api/**/resource")` | Restructure URL patterns to avoid `**` in middle of path | PathPatternParser default in WebFlux; opt-in for MVC | PathPatternParser (5.3) |
| `@ExceptionHandler` methods check all exception causes at any nesting level | behavioral | Only first cause checked (since 4.3) | All exception causes at any nesting level now checked | May match more broadly than before | Exception Handling (5.3) |
| Empty query params requiring type conversion treated as missing if result is null | behavioral | Empty `@RequestParam` converted to default value | Empty value for `UUID`, `Long`, etc. treated as missing; set `required=false` or `@Nullable` to allow | Applies to `@RequestParam`, `@RequestHeader`, and similar | Type Conversion (5.3) |
| `@Nested` JUnit test classes inherit test annotations from enclosing classes by default | behavioral | Annotations not inherited from enclosing class | Annotations inherited by default; use `@NestedTestConfiguration(OVERRIDE)` to restore old behavior | Or set `spring.test.enclosing.configuration=override` globally | Testing (5.3) |
| `LocaleResolver`, `ThemeResolver`, `FlashMapManager` must be declared in `@EnableWebMvc` config class | structural | Declare beans anywhere in context | Declare in `@EnableWebMvc`-annotated config class using well-known bean names | Applies to non-Spring Boot JavaConfig projects | Spring MVC Beans (5.3) |
| Suffix pattern matching (`.*`) disabled by default | behavioral | `/person.json` matched `/person` controller | Suffix matching no longer performed; use `Accept` header or query parameter | Path extensions no longer used for content type interpretation | Suffix Pattern (5.3) |
| JSON `HttpMessageConverter` flushes to response even on serialization errors | behavioral | | Response partially written before error; cleanup occurs automatically | | JSON Serialization (5.3) |
| `java.security.Principal` argument no longer resolved eagerly if annotated | behavioral | `@AuthenticationPrincipal Principal p` resolved as `HttpServletRequest#getUserPrincipal` | `@AuthenticationPrincipal` now correctly injects `Authentication#getPrincipal` | Remove `@AuthenticationPrincipal` to inject top-level `Authentication` object | Principal Resolution (5.3) |
| Spring R2DBC module moved into Spring Framework core | addition | `io.r2dbc:r2dbc-spi` (external Spring Data R2DBC) | `spring-r2dbc` module with `R2dbcTransactionManager` built into framework | Native R2DBC support without Spring Data dependency | Data Access (5.3) |
| `@EventListener` methods default to `Ordered.LOWEST_PRECEDENCE` | behavioral | Arbitrary ordering | Explicit `@Order` required for custom ordering on all listener methods | Aligns with transaction synchronizations and `@TransactionalEventListener` | Core Container (5.3) |
| `BeanNameAutoProxyCreator` respects `beanNames` list with custom `TargetSourceCreator` | behavioral | Proxied beans regardless of beanNames list | Only proxies beans matching configured `beanNames` | | Core Container (5.3) |
| Reactive transactions roll back on Reactive Streams cancel signal | behavioral | Partial commits possible on cancel | Consistent rollback on cancel signal | Prevents partial commits in reactive transactions | Data Access (5.3) |
| `WebClient` exceptions wrapped in `WebClientRequestException`/`WebClientResponseException` | structural | Raw exceptions from HTTP client | Exceptions wrapped; `CodecException`s propagated unwrapped | | Spring WebFlux (5.3) |
| `UriComponentsBuilder` injected into `@Controller` is now application-relative | behavioral | No path in injected builder | Includes `contextPath` | | Spring WebFlux (5.3) |
| Remoting (Hessian, RMI, HTTP Invoker, JMS Invoker) deprecated with no replacement | removal | `@Bean HessianServiceExporter hessianExporter() { ... }` | Remove remoting infrastructure; use REST/messaging APIs | Deprecated in 5.3; removed in 6.0 | Third-Party APIs (5.3) |
| JCA CCI support deprecated | removal | JCA CCI connection factory and template usage | Use specific data access APIs or native CCI | Deprecated in 5.3; removed in 6.0 | Third-Party APIs (5.3) |
| `MimeMessageHelper` aligned with JavaMail 1.5+; no longer explicitly encodes attachment filenames | behavioral | Attachment filenames explicitly encoded | Default encoding deferred to JavaMail | | Third-Party APIs (5.3) |
| `WebSocketConfigurationSupport` refactored to not require CGLIB proxies | structural | | CGLIB proxy no longer needed for WebSocket config support classes | | WebSocket (5.3) |
| MockMvc Kotlin DSL: use `isOk()` instead of `isOk` property syntax | structural | `mockMvc.get("/api") { }.andExpect { status { isOk } }` | `mockMvc.get("/api") { }.andExpect { status { isOk() } }` | Kotlin DSL revised in 5.3 | Testing (5.3) |
| `@RequestPart` with `List<T>` in WebFlux converts 1st part to list (consistent with MVC) | behavioral | Each part converted individually to `T` | First part converted to `List<T>` consistent with MVC and `T[]` | | Spring WebFlux (5.3) |
| `@EnableWebFlux` now includes `WebSocketHandlerAdapter` bean declaration | addition | `@Bean WebSocketHandlerAdapter adapter() { ... }` | Remove custom `WebSocketHandlerAdapter` declaration; framework provides it | Application-declared ones take priority | Spring WebFlux (5.3) |
| `WebTestClient` support for performing requests against `MockMvc` | addition | | Same `WebTestClient` API for MockMvc and full HTTP tests | Unifies testing approach | Testing (5.3) |
