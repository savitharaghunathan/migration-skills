# Pattern Map — Java EE 8 to Jakarta EE 10

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| Java 11 is the minimum baseline for Jakarta EE 10 (was Java 8 for Java EE 8) | addition | | JDK 11+ required at compile and runtime | JDK 17 recommended | Jakarta EE Platform |
| persistence.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/persistence" version="2.2"` | `xmlns="https://jakarta.ee/xml/ns/persistence" version="3.0"` | Update schema location URL and version attribute | XML namespaces — persistence.xml |
| web.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/javaee" version="4.0"` | `xmlns="https://jakarta.ee/xml/ns/jakartaee" version="6.0"` | Update schema location URL and version attribute | XML namespaces — web.xml |
| beans.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/javaee" bean-discovery-mode="all"` | `xmlns="https://jakarta.ee/xml/ns/jakartaee" version="4.0" bean-discovery-mode="all"` | Empty beans.xml still works but explicit version recommended | XML namespaces — beans.xml |
| ejb-jar.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/javaee" version="3.2"` | `xmlns="https://jakarta.ee/xml/ns/jakartaee" version="4.0"` | | XML namespaces — ejb-jar.xml |
| faces-config.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/javaee" version="2.3"` | `xmlns="https://jakarta.ee/xml/ns/jakartaee" version="4.0"` | | XML namespaces — faces-config.xml |
| validation.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/validation/configuration" version="2.0"` | `xmlns="https://jakarta.ee/xml/ns/validation/configuration" version="3.0"` | | XML namespaces — validation.xml |
| batch.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/javaee"` | `xmlns="https://jakarta.ee/xml/ns/jakartaee"` | Batch job XML files | XML namespaces — batch.xml |
| orm.xml namespace must change from JCP to Jakarta EE | structural | `xmlns="http://xmlns.jcp.org/xml/ns/persistence/orm" version="2.2"` | `xmlns="https://jakarta.ee/xml/ns/persistence/orm" version="3.0"` | JPA ORM mapping files | XML namespaces — orm.xml |
| Facelets XHTML namespace URIs must change for JSF/Faces | structural | `xmlns:h="http://xmlns.jcp.org/jsf/html"` | `xmlns:h="jakarta.faces.html"` | Also: `jsf/core`→`jakarta.faces.core`, `jsf/facelets`→`jakarta.faces.facelets`, `jsf/composite`→`jakarta.faces.composite`, `jsf/passthrough`→`jakarta.faces.passthrough` | XML namespaces — Facelets |
| JSTL tag library namespace URIs must change | structural | `xmlns:c="http://xmlns.jcp.org/jsp/jstl/core"` | `xmlns:c="jakarta.tags.core"` | Also: `jstl/fmt`→`jakarta.tags.fmt`, `jstl/functions`→`jakarta.tags.functions`, `jstl/sql`→`jakarta.tags.sql`, `jstl/xml`→`jakarta.tags.xml` | XML namespaces — JSTL |
| ServiceLoader files under META-INF/services/ must be renamed | structural | `META-INF/services/javax.servlet.ServletContainerInitializer` | `META-INF/services/jakarta.servlet.ServletContainerInitializer` | Rename all `META-INF/services/javax.*` files to `META-INF/services/jakarta.*` | ServiceLoader |
| CDI extension registration file must be renamed | structural | `META-INF/services/javax.enterprise.inject.spi.Extension` | `META-INF/services/jakarta.enterprise.inject.spi.Extension` | CDI portable extensions | ServiceLoader — CDI |
| Bean validation message interpolation tokens must change | structural | `{javax.validation.constraints.NotNull.message}` | `{jakarta.validation.constraints.NotNull.message}` | All constraint message keys use jakarta prefix | Validation messages |
| Bean validation constraint-mapping XML namespace must change | structural | `xmlns="http://xmlns.jcp.org/xml/ns/validation/mapping"` | `xmlns="https://jakarta.ee/xml/ns/validation/mapping"` | constraint-mappings XML files | XML namespaces — validation mapping |
| Entity Beans (CMP/BMP) removed from Jakarta EE 10 | removal | `@Entity` with `javax.ejb.EntityBean` interface | Migrate to Jakarta Persistence (`@Entity` with `jakarta.persistence`) | Entity Beans were already deprecated; now removed from the platform | EJB — Entity Beans |
| Embeddable EJB Container removed from Jakarta EE 10 | removal | `javax.ejb.embeddable.EJBContainer` | Use CDI SE (`SeContainerInitializer`) or application server testing tools | No longer a required platform feature | EJB — Embeddable Container |
| Jakarta Deployment API removed from platform | removal | `javax.enterprise.deploy.spi.DeploymentManager` | N/A — use server-specific deployment tools | API removed entirely | Removed specifications |
| Jakarta XML Registries (JAXR) removed from platform | removal | `javax.xml.registry.ConnectionFactory` | N/A — no direct replacement | API removed entirely | Removed specifications |
| Jakarta XML RPC removed from platform | removal | `javax.xml.rpc.Service` | Migrate to Jakarta XML Web Services (`jakarta.xml.ws`) or JAX-RS | API removed entirely | Removed specifications |
| Applet support removed from Jakarta EE 10 | removal | Applet-related deployment descriptors and APIs | N/A | Aligns with Java SE applet removal | Removed features |
| SecurityManager deprecated in Jakarta EE 10 | behavioral | Java Security Manager policy files and `System.setSecurityManager()` | Plan for removal — Security Manager deprecated in JDK 17 | Aligning with JDK deprecation | SecurityManager |
| Do NOT change Java SE javax.* packages | behavioral | `import javax.sql.DataSource;` | `import javax.sql.DataSource;` (NO CHANGE) | Java SE packages remain javax: `javax.sql`, `javax.crypto`, `javax.net`, `javax.naming`, `javax.xml.parsers`, `javax.xml.transform`, `javax.xml.datatype`, `javax.xml.validation`, `javax.security.auth` (base), `javax.annotation.processing`, `javax.transaction.xa`, `javax.management` (JMX), `javax.swing`, `javax.imageio`, `javax.sound` | Java SE exceptions |
| Do NOT change javax.transaction.xa (Java SE) | behavioral | `import javax.transaction.xa.XAResource;` | `import javax.transaction.xa.XAResource;` (NO CHANGE) | Part of Java SE JDBC, not Jakarta EE | Java SE exceptions — transactions |
| Do NOT change javax.annotation.processing (Java SE) | behavioral | `import javax.annotation.processing.Processor;` | `import javax.annotation.processing.Processor;` (NO CHANGE) | Annotation processing is Java SE, not Jakarta EE | Java SE exceptions — annotations |
| Do NOT change javax.security.auth base package (Java SE) | behavioral | `import javax.security.auth.Subject;` | `import javax.security.auth.Subject;` (NO CHANGE) | Only `javax.security.auth.message.*` moves to jakarta; base `javax.security.auth` is Java SE | Java SE exceptions — security |
| Mixing javax and jakarta dependencies causes runtime errors | behavioral | | | Do not mix javax.* and jakarta.* EE dependencies in the same application; causes ClassNotFoundException and namespace collisions | Migration approach |
| Eclipse Transformer can convert third-party JARs not yet migrated | addition | | Apply Eclipse Transformer to unconverted dependencies at build time | Creates bytecode-level javax→jakarta transformation on existing JARs | Migration tools |
| API artifacts now include module-info.class | addition | | | Jakarta EE 10 API JARs are modular; may affect classpath/modulepath configuration | Jakarta EE Platform |
