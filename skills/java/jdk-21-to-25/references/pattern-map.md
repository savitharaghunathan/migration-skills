# Pattern Map — JDK 21 to 25

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| ZGC non-generational mode removed; ZGC now runs in generational mode only | behavioral | `-XX:+UseZGC` (non-generational by default in JDK 21) | `-XX:+UseZGC` (generational by default since JDK 23, non-gen removed in JDK 24) | Remove any `-XX:-ZGenerational` flags; generational is now the only mode | ZGC Changes (JDK 23, JDK 24) |
| Security Manager permanently disabled; all SecurityManager API calls are no-ops | removal | `System.setSecurityManager(sm); SecurityManager sm = System.getSecurityManager(); sm.checkPermission(perm);` | (remove all Security Manager usage — permanently disabled in JDK 24, JEP 486) | ~1000 methods across 264 classes previously threw SecurityException; those checks are now no-ops. Security properties `policy.provider`, `package.access`, `package.definition` are ignored | Permanently Disable the Security Manager (JDK 24) |
| JNI usage now emits warnings at runtime | behavioral | (JNI calls work silently) | (JNI calls emit runtime warnings on stderr) | JEP 472 in JDK 24; prepare for future restriction. Use `--enable-native-access` to suppress warnings | Prepare to Restrict JNI (JDK 24) |
| JNDI remote code downloading permanently disabled | removal | `env.put(Context.OBJECT_FACTORIES, "com.example.RemoteFactory")` | (remote code downloading disabled — use local factories only) | JNDI remote classloading disabled in JDK 24 | Removed APIs (JDK 24) |
| sun.misc.Unsafe memory-access methods emit runtime warning on first use | behavioral | (Unsafe memory methods work silently) | (first invocation emits runtime warning) | JEP 498 in JDK 24; migrate to VarHandle API or Foreign Function & Memory API | Warn upon Use of Unsafe (JDK 24) |
| Compact Object Headers now enabled by default | behavioral | (128-bit object headers) | (64-bit object headers by default in JDK 25) | Experimental in JDK 24 (`-XX:+UseCompactObjectHeaders`), product feature in JDK 25 (JEP 519). Code relying on object layout or identity hash internals may be affected | Compact Object Headers (JDK 25) |
| Graal JIT compiler removed | removal | `-XX:+UnlockExperimentalVMOptions -XX:+UseGraalJIT` | (remove — Graal JIT no longer available in JDK 25) | Experimental Graal JIT introduced in JDK 23, removed in JDK 25 | Removals (JDK 25) |
| String Templates feature withdrawn | removal | `String s = STR."Hello \{name}";` | (revert to `String.format()` or `+` concatenation — feature withdrawn in JDK 23) | Previewed in JDK 21 (JEP 430) and JDK 22 (JEP 459), withdrawn from JDK 23 with no replacement | String Templates (JDK 23) |
| Virtual threads no longer pin platform threads in synchronized blocks | behavioral | (virtual threads pinned to platform thread inside `synchronized`) | (virtual threads release platform thread when blocking in `synchronized`) | JEP 491 in JDK 24; this changes concurrency behavior — apps that relied on pinning behavior for implicit mutual exclusion may need review | Synchronize Virtual Threads (JDK 24) |
| JVM command line options -t, -tm, -Xfuture, -checksource, -cs, -noasyncgc removed | removal | `java -Xfuture MyApp` | (remove the flag) | These legacy options removed in JDK 24 | Removed APIs (JDK 24) |
| JVM command line options -Xnoagent removed | removal | `java -Xnoagent MyApp` | (remove the flag) | Deprecated in JDK 22, removed in JDK 23 | Removed APIs (JDK 23) |
| JVM command line options -Xdebug and -debug deprecated | removal | `java -Xdebug MyApp` | (remove the flag — no-op since JDK 22) | Deprecated for removal in JDK 22 | Deprecated for Removal (JDK 22) |
| JVM options -verbosegc, -noclassgc, -verify, -verifyremote, -ss, -ms, -mx deprecated for removal | behavioral | `java -verbosegc MyApp` or `java -ms256m -mx512m MyApp` | `java -verbose:gc MyApp` or `java -Xms256m -Xmx512m MyApp` | Deprecated for removal in JDK 24; use standard `-XX:` equivalents | Deprecated for Removal (JDK 24) |
| RegisterFinalizersAtInit VM option obsoleted | removal | `-XX:+RegisterFinalizersAtInit` | (remove the flag) | Obsoleted in JDK 23 | Removed APIs (JDK 23) |
| PreserveAllAnnotations VM option deprecated | removal | `-XX:+PreserveAllAnnotations` | (remove the flag) | Deprecated in JDK 23 | Deprecated for Removal (JDK 23) |
| DontYieldALot VM flag deprecated | removal | `-XX:+DontYieldALot` | (remove the flag) | Deprecated in JDK 23 | Deprecated for Removal (JDK 23) |
| UseEmptySlotsInSupers VM flag deprecated | removal | `-XX:+UseEmptySlotsInSupers` | (remove the flag) | Deprecated in JDK 23 | Deprecated for Removal (JDK 23) |
| UseNotificationThread VM option deprecated | removal | `-XX:+UseNotificationThread` | (remove the flag) | Deprecated in JDK 23 | Deprecated for Removal (JDK 23) |
| UseCompressedClassPointers VM option deprecated | removal | `-XX:+UseCompressedClassPointers` | (remove the flag — compact object headers subsumes this) | Deprecated in JDK 25 | Deprecated for Removal (JDK 25) |
| LockingMode flag and LM_LEGACY/LM_MONITOR modes deprecated | removal | `-XX:LockingMode=1` | (remove the flag) | Deprecated in JDK 24 | Deprecated for Removal (JDK 24) |
| VFORK launch mechanism deprecated on Linux | behavioral | (Process may use vfork internally) | (vfork deprecated; posix_spawn used instead) | Deprecated for removal in JDK 25 | Deprecated for Removal (JDK 25) |
| JDK1.1 compatible behavior for EST, MST, HST time zones removed | behavioral | `TimeZone.getTimeZone("EST")` returns `GMT-5` (JDK 1.1 compat) | `TimeZone.getTimeZone("EST")` returns IANA `America/New_York` or equivalent | JDK 1.1 compatibility behavior removed in JDK 24 | Removed APIs (JDK 24) |
| jdeps -profile and -P option removed | removal | `jdeps -profile myapp.jar` | `jdeps myapp.jar` (use `--multi-release` or other options) | Removed in JDK 22 | Removed APIs (JDK 22) |
| jstatd deprecated for removal | removal | `jstatd` | (use JMX or JFR for remote monitoring) | Deprecated in JDK 24 | Deprecated for Removal (JDK 24) |
| jrunscript deprecated for removal | removal | `jrunscript myscript.js` | (use external scripting runtime) | Deprecated in JDK 24 | Deprecated for Removal (JDK 24) |
| jhsdb debugd deprecated for removal | removal | `jhsdb debugd --pid <pid>` | (use alternative debugging approach) | Deprecated in JDK 24 | Deprecated for Removal (JDK 24) |
| JMX Subject Delegation removed | removal | (JMX subject delegation usage) | (remove — feature removed in JDK 23) | JMX Subject Delegation no longer available | Removed APIs (JDK 23) |
| JMX Management Applet (m-let) removed | removal | (JMX m-let usage) | (remove — feature removed in JDK 23) | JMX m-let feature no longer available | Removed APIs (JDK 23) |
| serialVersionUID compatibility logic from JMX removed | removal | (relied on JMX serialVersionUID compat) | (update serialized objects if needed) | Removed in JDK 24 | Removed APIs (JDK 24) |
| Old JMX system properties removed | removal | (old JMX system properties) | (use standard JMX properties) | Removed in JDK 25 | Removed APIs (JDK 25) |
| PerfData sampling removed | removal | (PerfData sampling) | (use JFR for performance data collection) | Removed in JDK 25 | Removed APIs (JDK 25) |
| sun.rt._sync* performance counters removed | removal | (sun.rt._sync* counters) | (use JFR events for synchronization data) | Removed in JDK 25 | Removed APIs (JDK 25) |
| Baltimore CyberTrust Root CA certificate removed | removal | (trusted by default) | (no longer in default truststore) | Certificate expired; removed in JDK 25 | Removed APIs (JDK 25) |
| Two Camerfirma Root CA certificates removed | removal | (trusted by default) | (no longer in default truststore) | Removed in JDK 25 | Removed APIs (JDK 25) |
| SunPKCS11 PBE-related SecretKeyFactory implementations removed | removal | `SecretKeyFactory.getInstance("PBE", "SunPKCS11-...")` | (use alternative provider or algorithm) | Removed in JDK 25 | Removed APIs (JDK 25) |
| XML interchange in JMX DescriptorSupport deprecated for removal | removal | `DescriptorSupport.toXMLString()` | (use alternative serialization) | Deprecated in JDK 25 | Deprecated for Removal (JDK 25) |
| Various Permission classes deprecated for removal | removal | `new FilePermission(...)`, `new SocketPermission(...)`, etc. | (remove — Security Manager permanently disabled) | Deprecated in JDK 25; part of ongoing Security Manager removal | Deprecated for Removal (JDK 25) |
| GTK2 support removed on Linux desktop | removal | (GTK2-based Swing rendering on Linux) | (use GTK3; set `-Djdk.gtk.version=3` if needed) | Removed in JDK 24 | Removed APIs (JDK 24) |
| Enhanced jar file validation in JDK 25 | behavioral | (lenient jar validation) | (stricter jar validation) | May reject previously accepted malformed jar files | Security Updates (JDK 25) |
| JFR cooperative sampling changes stack walking behavior | behavioral | (JFR async stack sampling) | (JFR stack walking restricted to safepoints, JEP 518) | JFR profiles may show different call stacks; monitoring dashboards may need adjustment | Monitoring (JDK 25) |
| Old core reflection implementation removed | removal | (old reflection impl used internally) | (new implementation only) | Removed in JDK 22; transparent to most code but reflection-heavy frameworks should test | Removed APIs (JDK 22) |
| Aligned access modes removed from MethodHandles::byteArrayViewVarHandle and byteBufferViewVarHandle | removal | `MethodHandles.byteBufferViewVarHandle(int[].class, ByteOrder.BIG_ENDIAN)` with aligned access modes | (use unaligned access modes only; aligned access modes removed in JDK 23) | Aligned access modes for byte array/buffer view VarHandles removed | Removed APIs (JDK 23) |
| JVM TI GetObjectMonitorUsage no longer supports virtual threads | behavioral | (GetObjectMonitorUsage works on virtual threads) | (GetObjectMonitorUsage returns error for virtual threads) | JVM TI agents using this function on virtual threads must be updated; deprecated in JDK 23 | Deprecated for Removal (JDK 23) |
