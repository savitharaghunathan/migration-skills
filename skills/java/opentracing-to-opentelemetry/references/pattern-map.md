# Pattern Map — OpenTracing to OpenTelemetry

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| Tracer initialization changes from Jaeger-specific builder to OTel SDK autoconfigure or programmatic setup | structural | `Configuration config = Configuration.fromEnv(); Tracer tracer = config.getTracer();` | `OpenTelemetry otel = AutoConfiguredOpenTelemetrySdk.initialize().getOpenTelemetrySdk(); Tracer tracer = otel.getTracer("service-name");` | Use `opentelemetry-sdk-extension-autoconfigure` for env-var based config, or build `SdkTracerProvider` programmatically | Migration Strategy |
| GlobalTracer registration replaced by GlobalOpenTelemetry | structural | `GlobalTracer.register(tracer);` | `GlobalOpenTelemetry.set(openTelemetry);` | In OTel, you set the full OpenTelemetry instance, not just a Tracer | Core API Mapping |
| Span activation pattern changes from ScopeManager to makeCurrent | structural | `Scope scope = tracer.activateSpan(span);` or `Scope scope = tracer.scopeManager().activate(span);` | `Scope scope = span.makeCurrent();` | Scope is still AutoCloseable; use try-with-resources | Core API Mapping |
| Getting active span changes from tracer method to static Span method | structural | `Span activeSpan = tracer.activeSpan();` | `Span activeSpan = Span.current();` | Static method on Span class | Core API Mapping |
| Error handling changes from tag-based to StatusCode + recordException | structural | `span.setTag(Tags.ERROR, true); span.log(Map.of("event", "error", "error.object", e));` | `span.setStatus(StatusCode.ERROR); span.recordException(e);` | OTel separates error status from exception recording; both should be called | Error Handling Mapping |
| SpanKind moves from tag to SpanBuilder parameter | structural | `Span span = tracer.buildSpan("name").withTag(Tags.SPAN_KIND, Tags.SPAN_KIND_SERVER).start();` | `Span span = tracer.spanBuilder("name").setSpanKind(SpanKind.SERVER).startSpan();` | SpanKind must be set before span starts; cannot be changed after | Span Kind Mapping |
| Baggage is independent from Span context in OTel | behavioral | `span.setBaggageItem("key", "value"); String val = span.getBaggageItem("key");` | `Baggage baggage = Baggage.current().toBuilder().put("key", "value").build(); try (Scope s = baggage.makeCurrent()) { String val = Baggage.current().getEntryValue("key"); }` | Baggage set via OpenTracing API is NOT accessible via OpenTelemetry API; migrate all baggage calls together | Baggage Changes |
| Propagation format changes from Jaeger to W3C TraceContext | behavioral | Header: `uber-trace-id: {trace-id}:{span-id}:{parent-span-id}:{flags}` | Header: `traceparent: {version}-{trace-id}-{span-id}-{trace-flags}` | Jaeger format is supported but deprecated in OTel; W3C TraceContext is the default | Propagation Format Changes |
| Baggage header format changes from Jaeger to W3C Baggage | behavioral | Header prefix: `uberctx-{key}: {value}` | Header: `baggage: key=value` | W3C Baggage standard replaces Jaeger baggage headers | Propagation Format Changes |
| Child span creation pattern changes | structural | `Span child = tracer.buildSpan("child").asChildOf(parentSpan).start();` | `Span child = tracer.spanBuilder("child").setParent(Context.current().with(parentSpan)).startSpan();` | Parent is set via Context in OTel, not directly on SpanBuilder | Method Mapping |
| Span log to event conversion | structural | `span.log(Map.of("event", "cache.miss", "cache.key", key));` | `span.addEvent("cache.miss", Attributes.of(AttributeKey.stringKey("cache.key"), key));` | Log key-value maps become named Events with typed Attributes | Method Mapping |
| Context injection/extraction pattern changes | structural | `tracer.inject(span.context(), Format.Builtin.HTTP_HEADERS, new TextMapAdapter(headers));` | `GlobalOpenTelemetry.getPropagators().getTextMapPropagator().inject(Context.current(), headers, Map::put);` | OTel uses typed TextMapSetter/TextMapGetter interfaces | Core API Mapping |
| @WithSpan creates a new child span unlike @Traced which modifies current | behavioral | `@Traced(operationName = "myOp")` on JAX-RS endpoint modifies the current span name | `@WithSpan("myOp")` on JAX-RS endpoint creates a NEW child span | Do not use @WithSpan on JAX-RS/Spring MVC endpoints that are already auto-instrumented; it creates unnecessary nested spans | Annotation Mapping |
| Sampler type value mapping | addition | `JAEGER_SAMPLER_TYPE=const` with `JAEGER_SAMPLER_PARAM=1` | `OTEL_TRACES_SAMPLER=always_on` | Mapping: `const`(1)→`always_on`, `const`(0)→`always_off`, `probabilistic`→`traceidratio`, `ratelimiting`→custom | Configuration Property Changes |
| OTLP exporter replaces Jaeger Thrift/gRPC exporter | addition | Jaeger Thrift endpoint: `http://localhost:14268/api/traces` | OTLP gRPC endpoint: `http://localhost:4317` or OTLP HTTP endpoint: `http://localhost:4318` | Jaeger backend supports OTLP natively since v1.35 | Configuration Property Changes |
| OpenTelemetry BOM should be added to dependency management | addition | N/A | `<dependencyManagement><dependencies><dependency><groupId>io.opentelemetry</groupId><artifactId>opentelemetry-bom</artifactId><type>pom</type><scope>import</scope></dependency></dependencies></dependencyManagement>` | Manages all io.opentelemetry artifact versions centrally | Dependency Changes |
