# Pattern Map — Spring Boot 3 to 4

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| Spring Boot 4 requires Java 17+, Jakarta EE 11, Servlet 6.1, Spring Framework 7.x, Kotlin 2.2+, GraalVM 25+ | addition | | Verify runtime meets requirements | | Review System Requirements |
| Undertow support removed; use Tomcat or Jetty as embedded server | removal | `spring-boot-starter-undertow` in build file | Replace with `spring-boot-starter-tomcat` or `spring-boot-starter-jetty` | Undertow is not compatible with Servlet 6.1 | Undertow |
| Pulsar Reactive auto-configuration removed | removal | `@Autowired ReactivePulsarTemplate template;` | Remove reactive Pulsar usage or manage manually | Spring Pulsar removed reactor support | Pulsar Reactive |
| Embedded executable uber jar launch scripts removed | removal | `<executable>true</executable>` in Maven plugin config | Remove executable config; use `java -jar` or Gradle application plugin | Unix-specific feature with limitations removed | Embedded Executable Uber Jar Launch Scripts |
| Spring Session Hazelcast removed from Spring Boot | removal | Spring Session Hazelcast auto-configuration | Add Hazelcast session dependency manually | Now maintained by Hazelcast team | Spring Session Hazelcast |
| Spring Session MongoDB removed from Spring Boot | removal | Spring Session MongoDB auto-configuration | Add MongoDB session dependency manually | Now maintained by MongoDB team | Spring Session MongoDB |
| Spock integration removed | removal | Spock-based Spring Boot tests | Migrate to JUnit 5; Spock does not yet support Groovy 5 | | Spock Integration |
| New modular design with smaller focused modules and new starter naming | structural | `spring-boot-autoconfigure` contains all auto-configurations | Each technology has dedicated module `spring-boot-<technology>` with root package `org.springframework.boot.<technology>` | Review starter table; use classic starters as migration stepping stone | Module Dependencies |
| Classic starters available for quick migration | addition | | Add `spring-boot-starter-classic` and `spring-boot-starter-test-classic` temporarily | Provides all modules like SB3; migrate away eventually | Classic Starters |
| Package structure changed to per-module organization | structural | `org.springframework.boot.autoconfigure.<feature>` | `org.springframework.boot.<module>.<subpackage>` | Each module starts with dedicated `org.springframework.boot.<module>` | Package Organization |
| Logback charset harmonized with Log4j2 | behavioral | (default charset varied) | Default charset is UTF-8 for file; Console#charset() for console | | Logback Default Charset |
| PropertyMapper no longer calls adapter/predicate when source is null | behavioral | `map.from(source::method).to(destination::method)` calls destination even for null | `map.from(source::method).always().to(destination::method)` to preserve null-mapping behavior | Review commit 239f384ac0 for adaptation examples | Property Mapper API Changes |
| Optional dependencies no longer included in uber jars by Maven | behavioral | Optional dependencies included in uber jar | Add `<includeOptional>true</includeOptional>` to build plugin config if needed | | Optional Dependencies in Maven |
| Classic Uber-Jar Loader removed | removal | Maven: `<loaderImplementation>CLASSIC</loaderImplementation>` / Gradle: `loaderImplementation = org.springframework.boot.loader.tools.LoaderImplementation.CLASSIC` | Remove loaderImplementation config from Maven/Gradle build files | | Classic Uber-Jar Loader Support |
| CycloneDX Gradle Plugin minimum version is 3.0.0 | addition | CycloneDX plugin < 3.0.0 | Update to CycloneDX Gradle plugin >= 3.0.0 | | Cyclone DX Gradle Plugin |
| Jackson 3: group IDs changed from com.fasterxml.jackson to tools.jackson | structural | `import com.fasterxml.jackson.databind.ObjectMapper;` | `import tools.jackson.databind.json.JsonMapper;` | Exception: jackson-annotations stays at com.fasterxml.jackson.core group ID | Upgrading Jackson |
| Jackson auto-detection now registers all classpath modules | behavioral | Only well-known Jackson modules registered automatically | All modules on classpath registered; set `spring.jackson.find-and-add-modules=false` to disable | | Upgrading Jackson |
| Jackson 2 compatibility module available as stop-gap | addition | | Add `spring-boot-jackson2` dependency if unable to migrate to Jackson 3; properties under `spring.jackson2` | Deprecated; will be removed in future release | Jackson 2 Compatibility |
| Liveness and readiness probes enabled by default | behavioral | Probes not enabled by default | Probes enabled; health endpoint exposes liveness/readiness groups | Set `management.endpoint.health.probes.enabled=false` to disable | Liveness and Readiness Probes |
| Fonts added to common static resource locations | behavioral | `/fonts/**` not included in static resources | `/fonts/**` now included; has same security settings | Exclude with `StaticResourceLocation.FONTS` if unwanted | Fonts Added to Common Static Locations |
| HttpMessageConverters deprecated; use customizers instead | structural | `@Bean HttpMessageConverters converters() { ... }` | Declare `ClientHttpMessageConvertersCustomizer` and/or `ServerHttpMessageConvertersCustomizer` beans | Contributing standalone HttpMessageConverter beans no longer supported | HttpMessageConverters Deprecation |
| ForwardedHeaderFilter no longer auto-configured for WAR deployments | behavioral | `server.forward-headers-strategy=framework` worked in WAR | `@Bean FilterRegistrationBean<ForwardedHeaderFilter> forwardedHeaderFilter() { ForwardedHeaderFilter filter = new ForwardedHeaderFilter(); FilterRegistrationBean<ForwardedHeaderFilter> registration = new FilterRegistrationBean<>(filter); registration.setDispatcherTypes(DispatcherType.REQUEST, DispatcherType.ASYNC, DispatcherType.ERROR); registration.setOrder(Ordered.HIGHEST_PRECEDENCE); return registration; }` | Only affects WAR deployments to external containers | Forwarded Headers Strategy |
| Jersey 4.0 does not support Jackson 3; use spring-boot-jackson2 | addition | | Add `spring-boot-jackson2` for JSON processing with Jersey | | Jersey |
| Tomcat WAR deployment requires starter-tomcat-runtime | structural | `spring-boot-starter-tomcat` for WAR deployments | Use `spring-boot-starter-tomcat-runtime` instead | Only for WAR file deployments | Tomcat |
| Elasticsearch RestClient replaced by Rest5Client | structural | `RestClientBuilder` customization | Use `Rest5ClientBuilderCustomizer`; elasticsearch-rest-client module no longer needed | Client code consolidated in co.elastic.clients:elasticsearch-java | Elasticsearch Client |
| MongoDB UUID and BigDecimal representations now require explicit configuration | behavioral | Default representations provided by Spring Data MongoDB | Set `spring.mongodb.representation.uuid` and `spring.data.mongodb.representation.big-decimal` explicitly | Aligns with driver recommendation | MongoDB UUID and BigDecimal Representations |
| Spring Batch now operates without database by default | behavioral | Spring Batch stores metadata in database | Use `spring-boot-starter-batch-jdbc` to restore DB metadata storage | spring-boot-starter-batch uses in-memory mode | Spring Batch |
| @SpringBootTest no longer provides MockMVC support | behavioral | `@SpringBootTest` auto-configures MockMVC | Add `@AutoConfigureMockMvc` annotation to test class | | Using MockMVC and @SpringBootTest |
| HtmlUnit settings restructured under htmlUnit attribute | structural | `@AutoConfigureMockMvc(webClientEnabled=false, webDriverEnabled=false)` | `@AutoConfigureMockMvc(htmlUnit = @HtmlUnit(webClient = false, webDriver = false))` | | Using MockMVC and @SpringBootTest |
| @SpringBootTest no longer provides WebClient or TestRestTemplate | behavioral | `@SpringBootTest` auto-configures TestRestTemplate | Add `@AutoConfigureTestRestTemplate` or `@AutoConfigureRestTestClient` annotation | Requires spring-boot-resttestclient and spring-boot-restclient dependencies | Using WebClient or TestRestTemplate and @SpringBootTest |
| @MockBean and @SpyBean cannot be used in @Configuration classes | behavioral | `@TestConfiguration public class TestConfig { @MockBean private UserService userService; @MockBean private OrderService orderService; @MockBean private PrintingService ps1; }` | `@SpringBootTest @MockitoBean(types = {OrderService.class, UserService.class}) @MockitoBean(name = "ps1", types = PrintingService.class) class ApplicationTests { ... }` | Can also create a custom `@SharedMocks` annotation with `@MockitoBean` | @MockBean and @SpyBean Removal |
| Spring Retry dependency management removed; use Spring Framework retry | structural | `@Retryable` from spring-retry | Migrate to Spring Framework retry or add explicit spring-retry version | | Dependency Management for Spring Retry |
| Spring Authorization Server version override changed | behavioral | `spring-authorization-server.version` property in pom.xml | Use `spring-security.version` instead | Authorization Server now part of Spring Security 7 | Dependency Management for Spring Authorization Server |
| Supporting both Spring Boot 3 and 4 in same artifact discouraged | behavioral | | Separate artifacts for SB3 and SB4 | Due to modularization effort | Considerations For Projects Building Their Own Starters |
| Test starters are now per-technology with test starter companions | structural | `spring-boot-starter-test` as single test dependency | Add `spring-boot-starter-<technology>-test` for each technology under test | Test starters bring spring-boot-starter-test transitively | Test Code |
| @WithMockUser and @WithUserDetails require security test starter | addition | Worked with spring-security-test on classpath | Add `spring-boot-starter-security-test` dependency | | Test Code |
| Kafka Streams customization: StreamBuilderFactoryBeanCustomizer removed | structural | `implements StreamBuilderFactoryBeanCustomizer` | `implements StreamsBuilderFactoryBeanConfigurer` (from Spring Kafka) | Configurer implements Ordered with default 0 | Kafka Streams Customization |
| AMQP retry customizers split into dedicated interfaces | structural | `implements RabbitRetryTemplateCustomizer` with target check | Use `RabbitTemplateRetrySettingsCustomizer` or `RabbitListenerRetrySettingsCustomizer` | Spring AMQP moved retry to Spring Framework | Spring AMQP Retry Features |
