# Pattern Map — Apache Camel 3.x to 4.0

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| Java 17 required; Java 11 support dropped | addition | | | Camel 4 requires Java 17 minimum | Java versions |
| slf4j upgraded from 1.7 to 2.0 | behavioral | | | May affect custom logging configurations | Logging |
| All JUnit 4 camel-test modules removed; JUnit 5 required | removal | `import org.apache.camel.test.junit4.CamelTestSupport` | `import org.apache.camel.test.junit5.CamelTestSupport` | Migrate all test classes to JUnit 5 | JUnit 4 |
| String-to-File type converter removed | removal | `File f = context.getTypeConverter().convertTo(File.class, "/path")` | | Create File objects explicitly with `new File(path)` | Type Converter |
| InOnly and InOut EIPs removed | removal | `<inOnly uri="direct:foo"/>` | `<to uri="direct:foo" pattern="InOnly"/>` | Use SetExchangePattern or To with pattern attribute | EIP Changes |
| Poll Enrich endpoint URI stored as Exchange property instead of message header | behavioral | `exchange.getIn().getHeader("CamelToEndpoint")` | `exchange.getProperty("CamelToEndpoint")` | Key is CamelToEndpoint; consistent with other EIPs | Poll Enrich EIP |
| CircuitBreaker Resilience4j options changed from nested XML elements to attributes | structural | `<resilience4jConfiguration><timeoutEnabled>true</timeoutEnabled><timeoutDuration>2000</timeoutDuration></resilience4jConfiguration>` | `<resilience4jConfiguration timeoutEnabled="true" timeoutDuration="2000"/>` | Affects bulkheadEnabled, bulkheadMaxConcurrentCalls, bulkheadMaxWaitDuration, timeoutEnabled, timeoutExecutorService, timeoutDuration, timeoutCancelRunningFuture | CircuitBreaker EIP |
| XML DSL description changed from child element to attribute | structural | `<route id="myRoute"><description>Something</description><from uri="kafka:cheese"/>...</route>` | `<route id="myRoute" description="Something"><from uri="kafka:cheese"/>...</route>` | lang attribute also removed from description | XML DSL |
| Tracer and Backlog Tracer exclude internal events from Rest DSL, route templates, and Kamelets | behavioral | | | Enable traceTemplates=true to include them | Tracing |
| Backlog Tracer now traces InputStream message headers | behavioral | | | Headers of type InputStream are now traced; stream may be at end if read afterward | Tracing |
| UseOriginalMessage/UseOriginalBody now defensively copies body to StreamCache | behavioral | | | Body is now converted to StreamCache when enabled in OnException/OnCompletion/error handlers | UseOriginalMessage / UseOriginalBody |
| Health checks default to readiness only; liveness no longer default | behavioral | | | CamelContextCheck provides both readiness and liveness; only consumer health checks enabled by default | Camel Health |
| JMX MBeans now include doCatch and doFinally in processor tree | behavioral | | | Additional MBeans visible in JMX monitoring | JMX |
| ManagedChoiceMBean.choiceStatistics renamed to extendedInformation | structural | `mbean.choiceStatistics()` | `mbean.extendedInformation()` | ManagedFailoverLoadBalancerMBean.exceptionStatistics also renamed | JMX |
| CamelContextMBean and CamelRouteMBean removed dumpRouteAsXml overload | removal | `mbean.dumpRouteAsXml(resolvePlaceholders, resolveDelegateEndpoints)` | | Two-argument overload removed | JMX |
| dumpRoutes type changed from boolean to String on CamelContext | structural | `context.setDumpRoutes(true)` | `context.setDumpRoutes("xml")` | Allows specifying xml or yaml as dump format | API Changes |
| YAML DSL steps must be nested under from | structural | `- route:\n    from:\n      uri: "direct:info"\n    steps:\n    - log: "message"` | `- route:\n    from:\n      uri: "direct:info"\n      steps:\n      - log: "message"` | Backwards-compatible mode from Camel 3.14 removed | YAML DSL |
| Default XML serialization switched from JAXB to camel-xml-io | behavioral | | | ModelToXMLDumper now uses generated serializer from camel-xml-io instead of JAXB | XML serialization |
| OpenAPI Maven Plugin defaults to platform-http instead of servlet | behavioral | | | camel-restdsl-openapi-plugin now generates Rest DSL using platform-http as rest component | OpenAPI Maven Plugin |
| Category enum reduced from 83 to 37 values | removal | | | Custom components using removed Category values must choose from remaining 37 | Category |
| camel-bean method option requires .class suffix for type parameters | structural | `"bean:myBean?method=foo(com.foo.MyOrder, true)"` | `"bean:myBean?method=foo(com.foo.MyOrder.class, true)"` | Also applies to Java types: `bar(String.class, int.class)` | camel-bean |
| camel-box upgraded from Box SDK v2 to v4 with method signature changes | structural | | | File thumbnail retrieval method no longer available | camel-box |
| camel-http upgraded to Apache HttpComponents v5; timeout options restructured | structural | `httpClient.socketTimeout=5000` | `httpClient.responseTimeout=5000` | Now 4 timeout options: connectionRequestTimeout, connectTimeout, soTimeout, responseTimeout; soTimeout must use httpConnection. prefix | camel-http |
| camel-google API components upgraded from Google SDK v1 to v2 | structural | | | camel-google-drive and camel-google-sheets have API method changes; others remain identical | camel-google |
| camel-web3j upgraded from web3j 3.x to 5.0 with API changes | structural | | | Some previous API calls no longer available | camel-web3j |
| camel-spring-boot no longer includes camel-spring-xml | removal | | `<dependency><groupId>org.apache.camel.springboot</groupId><artifactId>camel-spring-boot-xml-starter</artifactId></dependency>` | Add camel-spring-boot-xml-starter to use legacy Spring XML beans files | Camel Spring Boot |
| Camel shutdown phase changed to allow Spring Boot graceful shutdown first | behavioral | | | getPhase() changed from Integer.MAX_VALUE to Integer.MAX_VALUE - 2049 | Graceful Shutdown |
| camel-platform-http-starter no longer uses camel-servlet; endpoints lose /camel prefix | structural | `http://localhost:8080/camel/myservice` | `http://localhost:8080/myservice` | Changed from camel-servlet to Spring HTTP server directly | camel-platform-http-starter |
| Suspended routes return HTTP 503 instead of 404 | behavioral | | | Affects camel-platform-http-vertx and camel-platform-http-starter | camel-platform-http-vertx |
| camel-optaplanner now uses SolverManager; URI path changed | structural | `from("optaplanner:problemName?configFile=solver.xml")` | `from("optaplanner:myProblemName")` | useSolverManager boolean removed; SolverManager can be passed as parameter or header | camel-optaplanner |
| camel-salesforce blob field DTOs no longer append Url to property names | structural | `dto.getContentVersionUrl()` | `dto.getContentVersion()` | | camel-salesforce |
| camel-jbang command renames and parameter changes | structural | `camel dependencies` | `camel dependency` | -dir changed to --dir; camel stop now stops all by default (--all removed); placeholder syntax changed from $name to #name | camel-jbang |
| Micrometer metric names changed to follow naming conventions | structural | `CamelExchangeEventNotifier` | `camel.exchange.event.notifier` | All 11 metric names renamed: CamelExchangesFailed→camel.exchanges.failed, CamelExchangesSucceeded→camel.exchanges.succeeded, etc. | camel-micrometer |
| camel-file readLock=changed with readLockMinAge restored to 3.x behavior | behavioral | | | Using readLockMinAge=5s picks up files older than 5s from startup; existing old files picked up immediately | Upgrading Camel 4.0.1 to 4.0.2 |
| camel-fhir hapi-fhir upgraded from 4.2.0 to 6.2.4 | structural | | | Delete API return type changed; see hapi-fhir documentation for details | camel-fhir |
| apicurio-data-models upgraded from 1.1.27 to 2.0.3 in camel-openapi-rest-dsl-generator | structural | | | Underlying model classes changed | camel-openapi-rest-dsl-generator |
| camel-jpa transactionManager option removed; use transactionStrategy | structural | `from("jpa:MyEntity?transactionManager=#txManager")` | `from("jpa:MyEntity?transactionStrategy=#txStrategy")` | Vendor-neutral abstraction for Spring Transaction or Quarkus Transaction | camel-jpa |
| PluginHelper provides access to extensions previously on CamelContext | addition | | `ManagedCamelContext managed = camelContext.getCamelContextExtension().getContextPlugin(ManagedCamelContext.class)` | Also RoutesLoader and other advanced features accessed via getContextPlugin | API Changes |
