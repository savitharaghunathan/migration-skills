# Pattern Map

| description | category | before | after | notes | source_section |
|---|---|---|---|---|---|
| Replace DES encryption with AES-GCM authenticated encryption | removal | `block, _ := des.NewCipher(key8)` | `block, _ := aes.NewCipher(key32); gcm, _ := cipher.NewGCM(block); ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)` | DES has 56-bit key and 64-bit block (Sweet32). AES-GCM provides authenticated encryption | Weak Algorithms |
| Replace 3DES encryption with AES-GCM | removal | `block, _ := des.NewTripleDESCipher(key24)` | `block, _ := aes.NewCipher(key32); gcm, _ := cipher.NewGCM(block); ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)` | 3DES has 64-bit block (Sweet32). Use AES-128 or AES-256 | Weak Algorithms |
| Replace RC4 stream cipher with AES-GCM | removal | `c, _ := rc4.NewCipher(key); c.XORKeyStream(dst, src)` | `block, _ := aes.NewCipher(key); gcm, _ := cipher.NewGCM(block); ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)` | RC4 prohibited by RFC 7465 | Weak Algorithms |
| Replace CBC mode without authentication with AES-GCM | behavioral | `mode := cipher.NewCBCEncrypter(block, iv); mode.CryptBlocks(ciphertext, plaintext)` | `gcm, _ := cipher.NewGCM(block); ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)` | CBC without HMAC is vulnerable to padding oracles (Lucky13). GCM provides built-in authentication | Weak Algorithms |
| Replace CFB/OFB/CTR mode without authentication with AES-GCM | behavioral | `stream := cipher.NewCFBEncrypter(block, iv); stream.XORKeyStream(ciphertext, plaintext)` | `gcm, _ := cipher.NewGCM(block); ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)` | Unauthenticated modes allow ciphertext manipulation. Use GCM or CCM for authenticated encryption | Weak Algorithms |
| Replace hardcoded cryptographic keys with runtime key generation | behavioral | `var key = []byte("my-secret-key-1234567890123456")` | `key := make([]byte, 32); if _, err := crypto_rand.Read(key); err != nil { panic(err) }` | Hardcoded keys are extractable from binaries (CWE-321). Generate at runtime or load from secure key management | Operational Security |
| Replace hardcoded IV/nonce with random generation | behavioral | `var iv = []byte("1234567890123456")` | `nonce := make([]byte, gcm.NonceSize()); if _, err := crypto_rand.Read(nonce); err != nil { panic(err) }` | Hardcoded IVs/nonces break semantic security (CWE-329). Generate unique nonce per operation | Operational Security |
| Replace math/rand with crypto/rand for security-sensitive randomness | behavioral | `token := make([]byte, 32); rand.Read(token)` | `token := make([]byte, 32); if _, err := crypto_rand.Read(token); err != nil { panic(err) }` | math/rand is predictable (CWE-338). Use crypto/rand for tokens, keys, nonces, salts | Operational Security |
| Replace static salt in password hashing with unique random salt | behavioral | `salt := []byte("fixed-salt-value")` | `salt := make([]byte, 16); crypto_rand.Read(salt)` | Static salts enable rainbow table attacks (CWE-760). Generate 16+ byte unique salt per password | Operational Security |
| Ensure GCM/AEAD nonce uniqueness per operation | behavioral | `nonce := globalNonce // reused across operations` | `nonce := make([]byte, gcm.NonceSize()); crypto_rand.Read(nonce)` | Nonce reuse with GCM breaks confidentiality and authentication. Generate fresh nonce per Seal call | Operational Security |
| Upgrade RSA keys from < 2048 bits to >= 2048 bits | behavioral | `key, _ := rsa.GenerateKey(rand.Reader, 1024)` | `key, _ := rsa.GenerateKey(rand.Reader, 2048)` | RSA < 2048 disallowed by SP 800-131A. 3072+ recommended for long-term keys | Key Strength |
| Replace P-224 curve with P-256 or P-384 | behavioral | `key, _ := ecdsa.GenerateKey(elliptic.P224(), rand.Reader)` | `key, _ := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)` | P-224 deprecated by NIST SP 800-186 | Key Strength |
| Increase PBKDF2 iteration count to >= 600000 | behavioral | `dk := pbkdf2.Key(pass, salt, 1000, 32, sha256.New)` | `dk := pbkdf2.Key(pass, salt, 600000, 32, sha256.New)` | OWASP recommends >= 600000 iterations for PBKDF2-SHA-256 | Key Strength |
| Enable Go 1.24+ native FIPS 140-3 mode | addition | | `GOFIPS140=latest go build ./...` | Build with GOFIPS140=latest to enable NIST-certified FIPS module. Non-FIPS algorithms will panic at runtime | FIPS Mode |
| Migrate from BoringCrypto to Go 1.24+ native FIPS mode | structural | `GOEXPERIMENT=boringcrypto go build ./...` | `GOFIPS140=latest go build ./...` | BoringCrypto fork superseded. Remove GOEXPERIMENT=boringcrypto, golang-fips/go references, and GOFIPS=1 | BoringCrypto Migration |
| Migrate from golang-fips/go fork to upstream Go 1.24+ | structural | `FROM golang-fips/go:1.22 AS builder` | `FROM golang:1.24 AS builder` | The golang-fips/go fork is no longer needed — Go 1.24+ has built-in FIPS support | BoringCrypto Migration |
| Remove GODEBUG=tlsmlkem=0 to enable PQC key exchange | addition | `os.Setenv("GODEBUG", "tlsmlkem=0")` | (remove — ML-KEM hybrid key exchange is enabled by default in Go 1.24+) | Disabling ML-KEM blocks quantum-resistant key exchange | PQC Configuration |
| Do not restrict CurvePreferences to block ML-KEM hybrid | behavioral | `CurvePreferences: []tls.CurveID{tls.X25519, tls.CurveP256}` | (remove CurvePreferences — let Go select curves including X25519MLKEM768) | Hardcoded CurvePreferences may exclude PQC hybrid key exchange | PQC Configuration |
| Do not block X25519 without ML-KEM hybrid fallback | behavioral | `CurvePreferences: []tls.CurveID{tls.X25519}` | (remove — Go 1.24+ automatically negotiates X25519MLKEM768 hybrid when both sides support it) | X25519-only preference without ML-KEM loses PQC protection | PQC Configuration |
| Inventory RSA usage for PQC migration planning | addition | | `// PQC-INVENTORY: RSA used for [purpose]. Plan migration to ML-DSA (FIPS 204) when ecosystem supports it` | RSA is quantum-vulnerable. Document all usages for future migration to ML-DSA | PQC Inventory |
| Inventory ECDSA usage for PQC migration planning | addition | | `// PQC-INVENTORY: ECDSA used for [purpose]. Plan migration to ML-DSA (FIPS 204) when ecosystem supports it` | ECDSA is quantum-vulnerable. Document for future ML-DSA migration | PQC Inventory |
| Inventory ECDH usage for PQC migration planning | addition | | `// PQC-INVENTORY: ECDH used for [purpose]. Go 1.24+ TLS already uses ML-KEM hybrid for key exchange` | ECDH is quantum-vulnerable but Go 1.24+ TLS handles hybrid automatically | PQC Inventory |
| Inventory Ed25519 usage for PQC migration planning | addition | | `// PQC-INVENTORY: Ed25519 used for [purpose]. Plan migration to ML-DSA (FIPS 204) when ecosystem supports it` | Ed25519 is quantum-vulnerable and not FIPS-approved | PQC Inventory |
| Inventory JWT RSA/ECDSA signatures for PQC migration planning | addition | | `// PQC-INVENTORY: JWT signed with [RS256/ES256]. HMAC signatures (HS256/384/512) are quantum-resistant` | RSA/ECDSA JWT signatures are quantum-vulnerable. HMAC-based JWTs are quantum-resistant | PQC JWT Signatures |
| Inventory X.509 certificate operations for PQC planning | addition | | `// PQC-INVENTORY: X.509 certificates use [algorithm]. Plan migration to PQC signature algorithms when CAs support them` | X.509 certs with RSA/ECDSA signatures will need PQC migration | PQC JWT Signatures |
| Inventory SSH key operations for PQC planning | addition | | `// PQC-INVENTORY: SSH keys use [algorithm]. Monitor OpenSSH PQC support for migration timeline` | SSH with RSA/ECDSA/Ed25519 keys will need PQC migration | PQC JWT Signatures |
| Replace custom tls.Config with hardened defaults | structural | `tlsConfig := &tls.Config{InsecureSkipVerify: true, MinVersion: tls.VersionTLS10, CipherSuites: customSuites}` | `tlsConfig := &tls.Config{MinVersion: tls.VersionTLS12, ServerName: "expected-host"}` | Minimal tls.Config with only MinVersion and ServerName. Let Go manage cipher suites and curve preferences for FIPS compliance | TLS Configuration |
| Replace gRPC WithInsecure with TLS credentials | structural | `conn, err := grpc.Dial(addr, grpc.WithInsecure())` | `creds := credentials.NewTLS(&tls.Config{MinVersion: tls.VersionTLS12}); conn, err := grpc.Dial(addr, grpc.WithTransportCredentials(creds))` | Unencrypted gRPC violates FIPS transport requirements | TLS Configuration |
| Fix database connections to use TLS | structural | `db, err := sql.Open("postgres", "host=db sslmode=disable")` | `db, err := sql.Open("postgres", "host=db sslmode=verify-full sslrootcert=/path/to/ca.crt")` | Database connections must use TLS with certificate verification | TLS Configuration |
| Replace NaCl Box with ECDH P-256 + AES-GCM | structural | `out := box.Seal(nil, message, &nonce, &peerPub, &priv)` | `privKey, _ := ecdh.P256().GenerateKey(rand.Reader); shared, _ := privKey.ECDH(peerPub); block, _ := aes.NewCipher(shared[:32]); gcm, _ := cipher.NewGCM(block); out := gcm.Seal(nonce, nonce, message, nil)` | NaCl primitives not FIPS-approved. Combine ECDH + AES-GCM | x/crypto Non-FIPS Packages |
| Replace NaCl Secretbox with AES-GCM | structural | `out := secretbox.Seal(nil, message, &nonce, &key)` | `block, _ := aes.NewCipher(key[:]); gcm, _ := cipher.NewGCM(block); out := gcm.Seal(nonce, nonce, message, nil)` | XSalsa20+Poly1305 not FIPS-approved. Use AES-GCM | x/crypto Non-FIPS Packages |
